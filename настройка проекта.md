<h1 align="center">Инструкция по настройки проекта kicad в соответствии с ГОСТ</h1>
<h4 align="justify">Скачайте файл конфигурации темы ГОСТ.json и поместите его по адрусу, где будут лежат темы для Kicad.</h4>
<h4 align="justify">Запустите Kicad.</h4>
<h4 align="justify">Зайдите в Настройки → настройки → Редактор схем</h4>
<h4 align="justify">
    <ul>
      <li>Параметры отображения</li>
        <ul>
          <li>Шрифт по умолчанию - OpenGost type B TT</li>
        </ul>
      <li>Сетки</li>
        <ul>
          <li>Настроить основную сетку на 2,5 мм</li>
          <li>Настроить вторую сетку на 1 мм.<br>Большинство элементов ГОСТ расчитаны на сетку 2,5 мм. В особых случаях применима сетка 1 и 0, 5 мм.</li>
        </ul>
      <li>Параметры редактирования</li>
        <ul>
          <li>Контур листа - чёрный</li>
        </ul>
      <li>Параметры обозначения</li>
        <ul>
          <li>Сортирование по оси X</li>
        </ul>
      <li>Цвета</li>
      <ul>
        <li>Открыть каталог тем и выбрать скачанную тему ГОСТ.json</li>
      </ul>
    </ul>
</h4>
<h4 align="justify">После создания проекта зайди в редактор схем и выполните:</h4>
<h4 align="justify">Файл → Параметры схемы</h4>
<h4 align="justify">
    <ul>
      <li>Общие</li>
        <ul>
          <li>Форматирование</li>
          <ul>
            <li>Обозначение части символа - .1</li>
          </ul>
          <li>Соединения</li>
          <ul>
            <li>Размер точки соединения - малый</li>
          </ul>
        </ul>
      <li>Проект</li>
        <ul>
          <li>Классы цепей</li>
            <ul>
              <li>Толщина проводлника - 0,5 мм.</li>
              <li>Толщина шины - 1 мм.</li>
              <li>Цвет - чёрный</li>
              <li>Стиль линии - сплошной</li>
            </ul>
        </ul>
    </ul>
</h4>
