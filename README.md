# GOST-kikad
<h1 align="center">ГОСТ в Kicad</h1>
<h4 align="justify">В данном репозитории хранятся инструкции по реализации ГОСТ в программе Kicad.</h4>
<h5 align="justify">Библиотеки символов расчитаны под сетку 2,5 мм. В репозитории
хранятся библиотеки аналоговых, цифровых элементов, а также отдельная библиотека с разъёмами.</h5>
<h5 align="justify">Цветовые темы, листы и подробная инструкция настройки ещё в разработке.</h5>
<h5 align="left">Перед началом работы необходимо:</h5>
<h3>
  <ul>
    <li>Установить шрифт OpenGost type B TT из данного репозитория</li>
    <li>Установить программу Kicad https://www.kicad.org/download/</li>
  </ul>
</h3>
<h5 align="left">Установка библиотек:</h5>
<h5>
  <ul>
    <li>Создайте на вашем компьютере папку под библиотеки</li>
    <li>Скачайте репозиторий libraries в подготовленную ранее папку</li>
    <li>Запустите Kicad и зайдите в редактор символов</li>
    <li>Выполните "Файл - Добавить библиотеку" и добавляйте по очереди каждую библиотеку</li>
    <li>Проверьте в тестовом проекте элементы на корректную работу</li>
  </ul>
</h5>

<h5 align="left">Обновление библиотек:</h5>
<h5>
  <ul>
    <li>Запустите Kicad и зайдите в редактор символов</li>
    <li>Выполните "Настройки - менеджер библиотек символов"</li>
    <li>Удалите старые библиотеки выбрав их и нажав на кнопку удалить</li>
    <li>Выполните действия по установке библиотек, начиная со второго пункта</li>
  </ul>
</h5>
<h4 align="justify">    ВНИМАНИЕ! Библиотеки, темы и листы находятся на этапе тестирования!</h4>
