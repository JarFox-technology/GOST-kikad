<h1 align="center">ГОСТ ЕСКД в Kicad</h1>
<h4 align="justify">Данный репозисторий содержит в себе инструкции, библиотеки и файлы настроек для реализации требований ГОСТ и ЕСКД к чертежам и схемам в САПР Kicad.</h4>
<h4 align="justify">Библиотеки символов расчитаны под сетку 2,5 мм. В репозитории
хранятся библиотеки аналоговых, цифровых элементов, а также отдельная библиотека с разъёмами.</h4>
<h4 align="justify"><i>ВНИМАНИЕ! Данный репозиторий находится на этапе разработки!</i><br>Возможны небольшие ошибки в работе системы.</h4>
<hr>
<h3 align="center">Перед началом работы необходимо:</h3>
<h4>
  <ul>
    <li>Установить шрифт OpenGost type B TT из данного репозитория</li>
    <li>Установить программу Kicad https://www.kicad.org/download/</li>
  </ul>
</h4>
<hr>
<h3 align="center">Настройка проекта</h3>
<h4>Инструкия по настройке проекта в kicad описана в файле <i>настройка проекта.md</i></h4>
<hr>
<h3 align="center">Установка форматной рамки чертежа:</h3>
<h4>
  <ul>
    <li>Скачайте рамку из папки template</li>
    <li>Перенесите рамку в подготовленную папку под форматные рамки</li>
    <li>Запустите Kicad и зайдите в вашем проекте в редактор схем</li>
    <li>Выполните "Файл - Параметры листа" и нажмите на иконку файлика в верхнем правом углу</li>
    <li>В открывшимся окне выберите скачанную рамку</li>
    <li>Настроте поля под ваш проект</li>
  </ul>
</h4>
<h4>Комментарий 7 - нижнее поле для материалов<br>Комментарий 8 - литера (запись трёх букв через пробел)<br>Комментарий 9 - масштаб (в схемах не указывается)</h4>
<h4>Остальной текст рисуется текстовыми полями.</h4>
<hr>
<h3 align="center">Установка библиотек символов:</h3>
<h4>
  <ul>
    <li>Создайте на вашем компьютере папку под библиотеки</li>
    <li>Скачайте репозиторий libraries в подготовленную ранее папку</li>
    <li>Запустите Kicad и зайдите в редактор символов</li>
    <li>Выполните "Файл - Добавить библиотеку" и добавляйте по очереди каждую библиотеку</li>
    <li>Проверьте в тестовом проекте элементы на корректную работу</li>
  </ul>
</h4>
<hr>
<h3 align="center">Обновление библиотек символов:</h3>
<h4>
  <ul>
    <li>Запустите Kicad и зайдите в редактор символов</li>
    <li>Выполните "Настройки - менеджер библиотек символов"</li>
    <li>Выберете старые библиотеки из списка и нажмите на кнопку удалить</li>
    <li>Выполните инструкцию по установке библиотек, начиная со второго пункта</li>
  </ul>
</h4>
